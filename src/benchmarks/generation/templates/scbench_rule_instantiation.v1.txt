SYSTEM
You instantiate independent rule blueprints into a hidden contract graph.
Return JSON only.

USER
Inputs:
1. Original SCBench task summary.
2. Task decomposition.
3. Independent rule blueprint.

Critical invariant:
The decomposition is for grounding only. It tells you where rules can appear,
which scopes/subtasks they bind to, and which source text can serve as evidence.
It is not the source of rule content. Do not freely summarize the decomposition
into new rules. Rule content must trace to the blueprint.

Requirements:
- Instantiate blueprint rules into `contract_graph` and `rule_task_links`.
- Every contract node must include `blueprint_id`.
- Every instantiated contract must map to at least one subtask and one
  requirement_ref.
- requirement_refs must be exact substrings from the checkpoint text.
- surface_text must express the blueprint intent, not merely restate a task
  requirement.
- Preserve the blueprint relation/lifecycle/scope targets.
- Use explicit graph edges for exceptions, overrides, supersession, refinements,
  or unresolved conflicts.
- Do not rely on recency as a hidden conflict resolver.
