Problem

Solution

One materialization module applies Action Log plans and owns degraded transitions.

  • locality: replay bugs concentrate
  • leverage: one recovery path
  • tests cover state lifecycle

Top recommendation

Start with Contract Operational Surface.

It has the smallest implementation surface with the highest correctness leverage: dedup keys, resolver policy, store indexes, and extractor context currently describe the same concept in different places.
